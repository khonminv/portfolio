### 🍞Wylie
Wylie 사이트를 리뉴얼 하였으며
GSAP를 활용해 스크롤 애니메이션과 동적 UI 인터랙션을 구현하며, 직관적인 네비게이션, 모바일 메뉴, 위치 기반 시각적 효과로 모바일과 웹에서 최적화된 사용자 경험을 제공합니다.
