### 🍞O'kichen
o'kichen을 리뉴얼하였으며 모바일 전용 웹 앱으로
HTML, CSS, JavaScript를 활용하여 반응형 웹 디자인과 모바일 내비게이션 기능을 제공하고 Google Maps API와 Swiper.js를 이용해 동적인 지도 표시와 슬라이더 효과 등을 구현하였습니다.

* HTML, CSS, JavaScript를 활용한 반응형 웹 디자인 구현
