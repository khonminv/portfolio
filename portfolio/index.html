  • wylie

    Wylie 사이트를 리뉴얼하였으며, GSAP를 활용하여 스크롤 애니메이션과 동적 UI 인터랙션을 구현하였습니다. 직관적인 네비게이션과 모바일 메뉴, 위치 기반 시각적 효과를 통해 모바일과 웹에서 최적화된 사용자 경험을 제공하며, 사용자가 콘텐츠에 쉽게 접근할 수 있도록 설계된 이 프로젝트는 시각적으로 매력적이고 사용자 친화적인 인터페이스를 갖추고 있습니다.

  • O’kichen

    o'kichen을 리뉴얼하였으며, 모바일 전용 웹 앱으로 HTML, CSS, JavaScript를 활용하여 반응형 웹 디자인과 모바일 내비게이션 기능을 제공하였습니다. Google Maps API와 Swiper.js를 이용해 동적인 지도 표시와 슬라이더 효과를 구현하여 사용자에게 시각적으로 매력적이고 직관적인 인터페이스를 제공하며, 모바일 환경에서 최적화된 사용자 경험을 실현하였습니다.
