### 🍞고운세상
고운세상 사이트를 클론 코딩 하였으며
React와 GSAP를 활용해 스크롤 애니메이션과 동적 UI 인터랙션을 구현하며, ScrollTrigger와 Timeline 기법을 활용하여 모바일과 웹에서 최적화된 사용자 경험을 제공합니다.
